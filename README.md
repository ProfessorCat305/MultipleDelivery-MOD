

本Mod将原版配送器只能对一种物品进行配送扩展至同时对6种物品进行供应或需求

This Mod extends the original distributor's functionality from delivering only one item to simultaneously supplying or demanding up to six items

## 模组说明 | Mod Introduction
将配送器的物品种类从1种扩展至6种，支持同时对6种物品进行供应或需求，使配送器的使用更加灵活，适用于更多的场景。

使配送器与物流塔形成差异化竞争，物流塔负责大批量物品的运输，而配送器则适合小批量、多样化的物品供应和需求。特别是建筑超市的建造

禁用/卸载本mod前请确保存档中配送器无选择物品，以及没有配送运输机在路途中，否则不保证读档正常
